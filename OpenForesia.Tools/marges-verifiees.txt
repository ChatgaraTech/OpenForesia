# LES MARGES COURTES PROUVEES — lu par check-descriptors.sh.
#
# Une marge <= 2 n'est pas un defaut : elle est sure si le compteur d'images +0x40 ne depasse pas
# la marge moins un tant que la planche est posee. Cela se prouve a la main, corps par corps, contre
# Blaze.c ou le binaire. Une fois prouve, le site est note ici, et le script l'affiche « prouve » au
# lieu de le signaler.
#
# UNE PREUVE EST SCELLEE SUR LES CORPS DONT ELLE DEPEND. La quatrieme colonne les nomme ; la
# cinquieme est l'empreinte de leur texte, commentaires et lignes vides retires. Qu'un seul de ces
# corps change d'une instruction, l'empreinte ne correspond plus, le script affiche PREUVE PERIMEE
# et le site redevient a verifier. Un commentaire retouche ne perime rien.
#
# Pour ajouter une preuve : ecrire la ligne avec la cinquieme colonne VIDE, puis
#   sh OpenForesia.Tools/check-descriptors.sh --sceller
# qui pose l'empreinte des lignes non scellees, et d'elles seules. Une preuve PERIMEE ne se
# rescelle pas en vidant sa colonne sans avoir relu le corps : c'est tout ce que le sceau protege.
#
# Les cles (trois premieres colonnes) sont celles que le script imprime.
# site | planche | decalage | corps dont depend la preuve | empreinte | pourquoi +0x40 reste dans la marge
#
# Verifiees le 2026-09-16.
