\# Comportement Legacy de la selection des personnages



\## Description

Description du comportement basic, c'est à dire des intérations minimale pour passer jusqu'à l'écran final et sauvegarder son personnage,

Je détaillerai ici surtout le comportement de la boite de dialogue



I. Arrivé sur le Caroussel des personnages\*



1. Boite de dialogue : Affiche "Sélectionne un personnage"
2. Appui sur "Entrer"
3. Boite de dialogue : Affiche "Ton choix se porte-t-il sur ce personnage ?"
4. Appui sur "Entrer"
5. Boite de dialogue : Affiche "Oui" et "Non" sur deux lignes avec le curseur 1P sur la ligne correspondante

Attention : Appuyer sur "Echap" durant les étape 3 ou 5 ou choisir "Non" à l'étape 5 résultera d'un retour à l'étape 1

Si choix "Oui" à l'étape 5 alors passe à l'écran suivant noté II (Choix du nom)



II. Arrivé sur l'écran Choix du Nom

1. Boite de dialogue : Affiche "Choisis un nom"

2\. On peut utiliser le clavier pour taper son nom

3\. Appui sur "Entrer" => Passe à l'écran noté III (Choix du langage)



III. Arrivé sur l'écran Choix du style de langage

1. Boite de dialogue : Affiche "Sélectionne le style de langage."
2. Appui sur "Entrer"
3. Boite de dialogue : Affiche : "Ton choix se porte-t-il sur ce style de langage  ?
4. Appui sur "Entrer"
5. Boite de dialogue : Affiche "Oui" et "Non" sur deux lignes avec le curseur 1P sur la ligne correspondante

Attention : Appuyer sur "Echap" durant les étape 3 ou 5 ou choisir "Non" à l'étape 5 résultera d'un retour à l'étape 1

Si choix "Oui" à l'étape 5 alors passe à l'écran suivant noté IV (Choix de la protection)



IV. Arrivé sur l'écran Choix de la protection

1. Boite de dialogue : Affiche "Sélectionne un élément de protection.
2. Appui sur "Entrer"
3. Boite de dialogue : Affiche "Ton choix se porte-t-il sur cet élément  ?
4. Appui sur "Entrer"
5. Boite de dialogue : Affiche "Oui" et "Non" sur deux lignes avec le curseur 1P sur la ligne correspondante

Attention : Appuyer sur "Echap" durant les étape 3 ou 5 ou choisir "Non" à l'étape 5 résultera d'un retour à l'étape 1

Si choix "Oui" à l'étape 5 alors passe à l'écran suivant noté V (Bonus)



V. Arrivé sur l'écran Bonus

1. Boite de dialogue : Affiche "Tu reçois un bonus."
2. Appui sur "Entrer" (carte 1 dévoilé)
3. Appui sur "Entrer" (carte 2 dévoilé)
4. Appui sur "Entrer" (carte 3 dévoilé)
5. Boite de dialogue : Affiche "Es-tu satisfait  ?"
6. Appui sur "Entrer"
7. Boite de dialogue : Affiche "Oui" et "Non" sur deux lignes avec le curseur 1P sur la ligne correspondante

Attention : Appuyer sur "Echap" durant les étape 5 ou 7 ou choisir "Non" à l'étape 5 résultera d'un retour à l'étape 1



Scénario alternatif écran Bonus

Après avoir dévoilé les trois cartes (fin étape 4 précédent), si les trois cartes sont identiques : 

4b. Boite de dialogue : Affiche "Bonus spécial  !n Tu peux retourner les cartes encore une fois" (Bonus spécial  ! est en jaune doré)

5b. Appui sur Entrer

6b. Reprise à l'étape 1 mais avec l'addition des bonus précédents, j'ai l'impression que si par chance incroyable l'utilisateur fait toujours des triplettes, alors le bonus peut se cumuler jusqu'à un maximum de 99



Si choix "Oui" à l'étape 7 alors passe à l'écran suivant noté VI (Application bonus)

1. Boite de dialogue : Affiche : "FO: force physique, importante pour l'attaque"
2. Appui sur "Fleche Droite" (pour accéder à INT)

3\. Boite de dialogue : Affiche "INT : intelligence, importante pour l'efficacité des sortilèges

4\. Appui sur "Fleche droite" (pour accéder à VO)

5\. Boite de dialogue : Affiche : "VO: volonté, importante pour résister aux sortilèges.

6\. Appui sur "Fleche droite" (pour accéder à AGI)

7\. Boite de dialogue : Affiche : "AGL: agilité, importante pour la défense."

8\. Appui sur "Fleche droite" (pour accéder à CON)

9\. Boite de dialogue : Affiche "CON: condition, importante pour la santé et la régénération."

10\. Appui sur "Fleche droite" (pour accéder à PM)

11\. Boite de dialogue : Affiche : "PM: pouvoir magiques, importants pour la volonté et la régénération"

12\. Appui sur "Fleche droite" (pour accéder à CH)

13\. Boite de dialogue : Affiche : "CH: chance, importante pour toute l'aventure"

14\. Appuyez ici sur "Fleche haut permet d'attribuer des bonus (ça décrémente bonus et incrémente le bonus sélectionner)

15\. Si tous les bonus sont appliqué (Bonus : 0) et appui sur "Entrer"

16\. Boite de dialogue : Affiche sur deux lignes : 

* Sauvegarder les personnages => Passage écran  noté VI "Enregistrement"
* Commencer à jouer malgré tout => Voir étape 17 juste après

17\. Boite de dialogue : Affiche : "Mise en garde. La sauvegarde ne fonctionne que si vous avez formé un groupe." (avec Mise en garde. en jaune doré)

18\. Appui sur Entrer

19\. Boite de dialogue : "Affiche : "Veux-tu commencer à jouer  ?"

20\. Appui sur Entrer

21\. Boite de dialogue : Affiche "Oui" et "Non" sur deux lignes avec le curseur 1P sur la ligne correspondante

* Choix Oui => Lance le jeu et arrive dans l'Auberge (hors scope pour l'instant)
* Choix Non => Retour à l'étape 1 (sans reset les bonus)



VI. Arrivé sur l'écran Enregistrement

1. Affichage d'une boite milieu écran de "récap" du personnage créé
2. Boite de dialogue : Affiche : "Enregistrement achevé"
3. Appui sur Entrer
4. Boite de dialogue affiche sur deux lignes : 
* Définir de nouveaux personnages => Retour à l'étape I. Arrivé sur le caroussel (création d'un nouveau personnage depuis le début)
* Constituer un groupe => Nous fait arriver sur un nouvel écran "Organisation du groupe", hors scope ici
